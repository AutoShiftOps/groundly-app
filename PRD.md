# Product Requirements Document

## Problem
Founders, MBA students, and consultants must run many disconnected strategic frameworks (PESTEL, Porter's, SWOT, TAM/SAM/SOM, STP, BCG, Ansoff, Value Chain, BMC, Balanced Scorecard) to validate a business idea. No single tool provides a grounded, cross-consistent, decision-ready synthesis.

## Target Users
- MBA students and early-stage founders (primary, free tier)
- Consultants and small business analysts (paid tier)
- Accelerators / cohorts (team/enterprise tier, future)

## Core Differentiators
1. RAG-grounded outputs — every claim cited, confidence-scored, no hallucinated numbers.
2. Cross-framework consistency — one retrieved dataset feeds all frameworks so TAM, SWOT, BCG do not contradict each other.
3. Tiered, toggle-based framework selection — free first-cut frameworks, paid deep-dive frameworks.
4. Engaging "train" progress UX during generation — reduces perceived wait and funnel drop-off.

## MVP Scope (Free Tier)
- PESTEL, SWOT, TAM (not SAM/SOM), Business Model Canvas
- Single idea-input wizard
- Grounded citations panel
- Train progress UI

## Paid Tier Scope
- Porter's Five Forces, VRIO, SAM/SOM, Competitive Benchmarking, STP (Targeting/Positioning), BCG, Ansoff, Value Chain, Balanced Scorecard, AI Decision Recommendation

## Success Metrics
- Landing page waitlist conversion > 10%
- Free-to-paid conversion > 3%
- Report generation time < 90 seconds end-to-end
- Citation coverage > 95% of claims

## Non-Goals (v1)
- No team collaboration features
- No mobile native app (responsive web only)
- No multi-language support at launch
