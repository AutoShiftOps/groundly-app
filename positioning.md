# Brand Positioning Constraints

| Pillar | Product Constraint |
|---|---|
| Functional | Every claim has citation + confidence score |
| Emotional | Reassuring copy, no black-box outputs |
| Social | Shareable summary cards per framework |
| Value | Free tier must be genuinely useful, not a teaser |
| Premium | Visual design matches premium SaaS bar |
| Innovation | Maintain RAG/grounding tech moat |
| Convenience | Zero learning curve, default toggles pre-set |
| Experience | Branded wait experience (train UI), no generic spinners |
| Community | Waitlist + founder community from day one |
| Ecosystem | Modular architecture for future sub-products |
