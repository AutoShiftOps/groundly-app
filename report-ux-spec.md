# Final Report UX Spec

## Layout
1. Header: logo, project name, date, Share, Export PDF
2. Hero verdict card: Go / Rework / Avoid, confidence %, source count
3. Insight card row (4-6 cards): Market Size, Competitive Pressure, Best Segment, Business Model Fit, Risk Flags
4. Left sidebar: framework segments (PESTEL, Porter's, SWOT, TAM/SAM/SOM, STP, BCG, Value Chain, BMC, Balanced Scorecard) — paid ones show lock icon
5. Main canvas: expandable framework card, tabs: Summary / Evidence / Assumptions / Actions
6. Right utility rail: citations list, Ask AI chat box, Compare Version button

## Interaction Rules
- Default toggles ON: PESTEL, SWOT, TAM, BMC
- Paid frameworks greyed with lock icon + upgrade CTA, never fully hidden
- Every claim has an inline citation chip [n] linking to source drawer
